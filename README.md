# Learning Approach

I don't want to just memorize APIs or copy code.

For each lesson, I try to understand:

1. What am I learning?
2. Why does it exist?
3. What problem does it solve?
4. Mental model
5. Code example
6. How the code works
7. What happens internally?
8. Common mistakes
9. Mini challenge
10. Practice & revision

The goal is to understand **why the backend works**, not just how to write the syntax.
